Endpoints ativos ✅
Endpoint	Função
POST /app/finalizarVenda	Fecha venda (grava receber/recebido/caixa)
POST /app/nfcePreparar	Prepara tabelas fiscais
POST /app/nfceEmitir	Prepara + gera TXT + transmite (com fallback contingência automática)
POST /app/nfceStatusSefaz	Consulta status SEFAZ + pendentes contingência
POST /app/nfceReprocessarContingencia	Transmite NFC-e em contingência (status 8 → 3)
Endpoint nfceEmitir — comportamento ✅

    Consulta detectarStatusSefaz()

    Se online: prepara (tpEmis=1), gera TXT, transmite → status 3 (autorizada)

    Se offline: prepara com tpEmis=9, gera TXT, assina mas NÃO transmite → status 8 (contingência)

    Suporta parâmetro forcar_contingencia: true para testes

Endpoint nfceReprocessarContingencia ✅

    Verifica status SEFAZ (aborta se ainda offline)

    Busca tab_nfce WHERE status_nfce = 8 (limite configurável)

    Para cada: chama transmitirXmlAssinado() → status 3 (autorizada) ou 4 (rejeitada)

    Retorna {total, autorizadas, rejeitadas, detalhes}
