O NfceGeradorTxt.php foi escrito com a Reforma Tributária SIMPLIFICADA — só gera os totais (dfe_gibstotal, dfe_gcbstotal), mas não gera o bloco <IBSCBS> por item. O schema pl_010d exige esse bloco. 6. Próximo passo exato
6.1 Extrair o bloco IBSCBS do TXT do VB6

Roda:
powershell

$txt = Get-Content "C:\WDS Comercial\NFCeGerada\2026\09\29\6014 29092026 1054.txt" -Raw
$matches = [regex]::Matches($txt, '^\w*UB\w*=.*$', 'Multiline')
$matches | Select-Object -First 40 | ForEach-Object { Write-Host $_.Value }

Isso mostra como o VB6 escreve o bloco IBSCBS no TXT (linhas CST_UB13, cClassTrib_UB14, pIBSUF_UB18, vIBSUF_UB35, pCBS_UB56, vCBS_UB67, vIS_UB11, etc.).
6.2 Confirmar as tabelas dfe_*
sql

SELECT 'gibsuf' AS t, COUNT(*) FROM dfe_gibsuf WHERE empresa=1 AND nfe=6015
UNION ALL SELECT 'gibsmun', COUNT(*) FROM dfe_gibsmun WHERE empresa=1 AND nfe=6015
UNION ALL SELECT 'gcbs',    COUNT(*) FROM dfe_gcbs    WHERE empresa=1 AND nfe=6015
UNION ALL SELECT 'class',   COUNT(*) FROM dfe_class_fiscal WHERE empresa=1 AND nfe=6015
UNION ALL SELECT 'is',      COUNT(*) FROM dfe_is      WHERE empresa=1 AND nfe=6015;

    Se todas > 0 → NfceFiscal OK, só falta o gerador incluir no TXT

    Se alguma = 0 → NfceFiscal também precisa ajuste
