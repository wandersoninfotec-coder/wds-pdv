1. Projeto e objetivo final

    ERP legado em VB6 + MySQL 4.1 (PDV, mesas, financeiro, caixa, estoque).

    Serviço intermediário em PHP que conversa com o banco.

    App Android de mesas em React Native/Expo (pronto).

    App web React → compilado em Electron (em construção) — foco atual.

    Objetivo final: emitir NFC-e (via DLL Tecnospeed) e depois integrar TEF (débito, crédito, PIX) no fechamento da venda.

2. Stack/ferramentas usadas

    Backend: PHP 7.4+/8.x + PDO + MySQL 5.7+/MariaDB + Apache (XAMPP/Linux).

    App Android: React Native 0.86 + Expo SDK 57, Axios, AsyncStorage.

    App web: React + Electron (versão NÃO INFORMADA).

    Criptografia de senha: algoritmo VB6 replicado em PHP (encriptar()).

    Fiscal: DLL Tecnospeed (nome exato do produto NÃO INFORMADO — ACBr/Integrador/TEF ainda não confirmado).

    Migração VB6 → PHP: classe NfceFiscal.php replica lógica do ERP.

5. Decisões de arquitetura/design já tomadas

    NFC-e emitida após fechamento da venda no PDV/app. vendas.status: 0=aberta, 1=fechada, 2=cancelada.

    vendas.vendedor = código do funcionário (não do usuário). funcionarios.USER é palavra reservada (usar backticks).

    Sessão/token: base64 simples (codigo:time:md5), 7 dias com renovação automática. Não é JWT.

    Modalidade de emissão: modelo 65, versão 4.00, ambiente homologação por padrão, série 1.

    Reforma Tributária (IBS/CBS/IS) já contemplada via tabelas dfe_*.

    Formas de pagamento mapeadas por tab_formapagamento.nfce_formapgto_vinculada (tPag SEFAZ).

    Regra VB6 mantida para troco: XML 4.00 grava valor cheio; versões anteriores descontam troco.
