7.2 Em paralelo — solução definitiva

Criar teste_props.php para descobrir a propriedade correta:
php

<?php
header('Content-Type: application/json; charset=utf-8');
$obj = new COM('NFCex.spdNFCeX');
$resultado = ['props' => [], 'metodos' => []];

$props = ['DiretorioTemplates','DiretorioEsquemas','DiretorioLog','DiretorioLogErro',
          'DiretorioTemporario','DiretorioXmlDestinatario','CaminhoTemplates',
          'CaminhoEsquemas','CaminhoConfig','Templates','Esquemas',
          'ArquivoConfiguracao','ArquivoConfig','ConfigFile','INIFile','Configuracao'];

foreach ($props as $p) {
    try { $resultado['props'][$p] = ['existe'=>true,'valor'=>(string)$obj->$p]; }
    catch (Throwable $t) { $resultado['props'][$p] = ['existe'=>false]; }
}
$metodos = ['LoadConfig','CarregarConfiguracao','CarregarConfig','LoadINI','Inicializar'];
foreach ($metodos as $m) {
    $resultado['metodos'][$m] = method_exists($obj, $m);
}
echo json_encode($resultado, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE);

8. Pegadinhas conhecidas

    ProgID é NFCex.spdNFCeX (com e minúsculo) — o X maiúsculo do OCX engana.

    Componente resolve templates por cwd do Apache, não do PHP. chdir no PHP não ajuda.

    extension=com_dotnet no php.ini não funciona em PHP antigo — precisa ser extension=php_com_dotnet.dll.

    ConverterLoteParaXml aceita string (não precisa de arquivo físico, mas VB6 usa).

    lkTXTDataSet = 1 (confirmado).

    PDO::ERRMODE_EXCEPTION obrigatório — sem isso, erros SQL somem.

    bindValue órfão = PDO ignora silenciosamente.

    PowerShell: aspas simples, comando em uma linha, usar curl.exe (não curl).

    MesaDetalhesModal.jsx (antigo) tem só alert — o correto é MesaDetalhesModal2.jsx.

    pagamentoService.js é o service correto (não mesaService.js).

    Divergência item × cabeçalho → rejeição 531/532.

    funcionarios.USER é palavra reservada SQL.

    vendas.vendedor = funcionarios.codigo.

    VB6 e PHP vão usar as mesmas pastas (Templates, Esquemas, NFCeGerada) — cuidado com concorrência.
