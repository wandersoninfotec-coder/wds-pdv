5. Plano do dia
🔴 Prioridade 1 — Bug multi-itens (2º item com NCM específico)

Sintoma: venda com 2 itens gera pIBSUF_UB18=0.00 no item 1 (que usa NCM 19059090 — tabela dfe_ncm_nbs_ibs_cbs).

Diagnóstico:
sql

SELECT produto, sequencial, pibsuf, vibsuf FROM dfe_gibsuf WHERE nfe=6025;
SELECT produto, sequencial, pibsmun, vibsmun FROM dfe_gibsmun WHERE nfe=6025;
SELECT produto, sequencial, pcbs, vcbs FROM dfe_gcbs WHERE nfe=6025;
SELECT item, produto, cst, cclasstrib FROM dfe_class_fiscal WHERE nfe=6025;

Se todas tiverem 2 linhas → problema no gerador TXT. Se faltar linha → problema no NfceFiscal.

Correção principal (NCM): NfceFiscal::processarReformaTributaria hoje zera as alíquotas quando busca por NCM:
php

'AliquotaIBSUF'  => 0, 'AliquotaIBSMun' => 0, 'AliquotaCBS' => 0,

Deve carregar da tabela dfe_ncm_nbs_ibs_cbs. Passos:

    SHOW COLUMNS FROM dfe_ncm_nbs_ibs_cbs — descobrir nomes reais

    Expandir Produto::buscarRtcPorNcm() para retornar alíquotas

    Ajustar processarReformaTributaria para usar os valores do NCM
