7. Aprendizados recentes (bugfix da impressão)
7.1 json_encode retornando false silenciosamente

    Causa: $nfce['xml_autorizado'] (8 KB) tinha bytes inválidos em UTF-8 → json_encode falhava → echo false imprime vazio

    Solução:

        Removido xml_autorizado do SELECT (substituído por CASE WHEN ... LIKE '%<tpEmis>9</tpEmis>%' THEN 1 ELSE 0 END AS contingencia)

        Uso de JSON_PARTIAL_OUTPUT_ON_ERROR | JSON_UNESCAPED_UNICODE

        sanitize via closure com mb_convert_encoding($v, 'UTF-8', 'ISO-8859-1')

7.2 catch (Exception $e) não pega tudo

    Em PHP 7.1, Error e TypeError não estendem Exception

    Usar sempre catch (Throwable $t) em métodos críticos

7.3 $dest = $sql->fetch(...) retorna false quando vazio

    Correção: $dest = $sql->fetch(PDO::FETCH_ASSOC) ?: null;

    Para o frontend, null é tratável; false não
