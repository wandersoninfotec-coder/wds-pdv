7. BUG ATUAL — endpoint nfceDadosImpressao
Sintoma

    Retorna vazio ao chamar

    Log C:\xampp\php\logs\php_error_log mostra:

text

nfceDadosImpressao RAW: {"empresa":1,"numero_nfce":6046}
nfceDadosImpressao JSON: stdClass Object ( [empresa] => 1 [numero_nfce] => 6046 )
PHP Notice: Undefined variable: resposta in appController.php on line 1978
nfceDadosImpressao resposta: null

Causa

$resposta não foi declarada antes do echo json_encode($resposta) (linha 1978). O array está sendo montado em outro formato (provavelmente echo json_encode([...]) direto), e a linha 1978 é duplicação.
Correção

Duas opções:

    A) Se antes da linha 1978 já existe um echo json_encode([...]), remover a linha 1978 (é duplicação)

    B) Se antes não existe, então declarar $resposta = [...]; e manter o echo json_encode($resposta);

Como decidir: rodar
powershell

Get-Content "C:\xampp\htdocs\app_mesas_api\controllers\appController.php" | Select-Object -Skip 1949 -First 40

E mandar o trecho das linhas 1950-1990.
Bônus — Trocar catch (Exception $e) por catch (Throwable $t)

Isso captura erros fatais (TypeError, Error) que o Exception não pega — evita "retorno vazio".
