5. Decisões de arquitetura

    O componente NÃO lê tabelas — lê TXT. Fluxo real:
    text

    VB6/PHP lê tabelas nfce_* → gera TXT
    → NFCe.ConverterLoteParaXml(txt, lkTXTDataSet=1, esquema) → XML
    → NFCe.AssinarNota(xml) → XML assinado
    → NFCe.EnviarNFSincrono('1', xmlAssinado, false) → retorno SEFAZ
    → parseia cStat/xMotivo/nProt/digVal → grava tab_nfce

    Pasta base: C:\WDS Comercial\NFCeGerada\ano\mes\dia\ (mesma do VB6).

    VB6 e Facilit coexistem — cuidado com numeração MAX(numero_nfce)+1.

    vendas.vendedor = código do funcionário (não usuário). funcionarios.USER = palavra reservada.

8. Pegadinhas conhecidas

    Componente não lê tabelas — só TXT.

    lkTXTDataSet = 1 (confirmado).

    ConverterLoteParaXml aceita string (não precisa de arquivo físico, mas VB6 usa).

    tab_nfce.status_nfce no VB6: 0=pendente, 1=validada, 3=autorizada, 4=rejeitada, 8=contingência.

    PDO::ERRMODE_EXCEPTION obrigatório — sem isso, erros de SQL somem.

    bindValue órfão = PDO ignora silenciosamente.

    PowerShell: aspas simples, comando em uma linha, curl.exe (não curl).

    MesaDetalhesModal.jsx (antigo) é alert — o correto é MesaDetalhesModal2.jsx.

    pagamentoService.js é o service correto (não mesaService.js).

    Divergência item × cabeçalho → rejeição 531/532.

    funcionarios.USER = palavra reservada SQL.

    vendas.vendedor = funcionarios.codigo.
