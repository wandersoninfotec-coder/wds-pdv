8. Pegadinhas conhecidas

    MesaDetalhesModal.jsx é versão antiga (só alert). Correto é MesaDetalhesModal2.jsx.

    pagamentoService.js é o service (não mesaService.js).

    bindValue órfão (placeholder inexistente na SQL) — PDO ignora silenciosamente. Sempre grep o placeholder na SQL.

    PDO::ERRMODE_EXCEPTION é obrigatório — sem isso, erros de SQL somem.

    tot_fp_codigo é INT — DLL faz padding para 01.

    PowerShell vs cmd: curl é alias de Invoke-WebRequest. Usar curl.exe ou Invoke-WebRequest.

    Quoting em PowerShell: aspas simples ('...'), sem \, comando em uma linha.

    funcionarios.USER é palavra reservada SQL.

    vendas.vendedor = funcionarios.codigo.

    Divergência item × cabeçalho = rejeição 531/532.

    Componente não é thread-safe.

    Teste cruzado (API + VB6) é a melhor estratégia de validação — VB6 aponta exatamente o que está errado.
