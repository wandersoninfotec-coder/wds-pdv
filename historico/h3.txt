1. Visão Geral do Projeto
1.1 Objetivo

Emitir NFC-e (modelo 65) automaticamente no fechamento da venda, tanto pelo Facilit (PDV desktop Electron) quanto pelo Facilit App (React Native/Android). Posteriormente: integração TEF (débito, crédito, PIX).
1.2 Componentes
Nome	Stack	Status
ERP VB6 (legado)	VB6 + MySQL 4.1	Em produção
Serviço PHP	PHP 7.4+/8.x + PDO + MySQL	Em desenvolvimento
Facilit App	React Native 0.86 + Expo SDK 57	Pronto (não emite NFC-e)
Facilit (PDV)	React + Electron	Em construção (emite NFC-e)
ERP 2.0	PHP (futuro)	Planejado
1.3 Fluxo de emissão
text

[Facilit/Electron]  ou  [Facilit App/Android]
        │
        ▼ POST /app/finalizarVenda
[PHP] Grava vendas, receber, recebido, recebido_formas, caixa_movimento
        │
        ▼ POST /app/nfceEmitir  (ou nfcePreparar + nfceTransmitir)
[PHP] NfceFiscal::prepararTudo()  ← ✅ VALIDADO
        │ popula tab_nfce, nfce_* e dfe_*
        ▼
[PHP] NfceTransmissor::transmitir()  ← ❌ PENDENTE
        │ chama componente TecnoSpeed via COM
        ▼
[Componente TecnoSpeed v6.0]  →  SEFAZ
        │
        ▼
[PHP] UPDATE tab_nfce (chave, protocolo, status)

5. Schemas de Tabelas (DESCOBERTOS)
5.1 nfce_totais
sql

CREATE TABLE `nfce_totais` (
  `emp_codigo` INT(11) NOT NULL DEFAULT '0',
  `numero_nfce` INT(11) NOT NULL DEFAULT '0',
  `tot_icms_vBC` DOUBLE, `tot_icms_vICMS` DOUBLE,
  `tot_icms_vBCST` DOUBLE, `tot_icms_vST` DOUBLE,
  `tot_icms_vProd` DOUBLE, `tot_icms_vFrete` DOUBLE,
  `tot_icms_vSeg` DOUBLE, `tot_icms_Desc` DOUBLE,
  `tot_icms_vII` DOUBLE, `tot_icms_vIPI` DOUBLE,
  `tot_icms_vPIS` DOUBLE, `tot_icms_vCOFINS` DOUBLE,
  `tot_icms_vOutro` DOUBLE, `tot_icms_vNF` DOUBLE,
  `vTotTrib` DOUBLE DEFAULT '0',
  `tot_icms_vFCP` DOUBLE DEFAULT '0',
  `tot_icms_vFCPST` DOUBLE DEFAULT '0',
  `tot_icms_vFCPSTRet` DOUBLE DEFAULT '0',
  `tot_icms_vIPIDevol` DOUBLE DEFAULT '0',
  PRIMARY KEY (`emp_codigo`,`numero_nfce`)
) ENGINE=INNODB DEFAULT CHARSET=latin1;

⚠️ Nomes de colunas têm prefixo tot_icms_ — não usar vBC, vProd, etc.
5.2 nfce_totais_formapgto
sql

CREATE TABLE `nfce_totais_formapgto` (
  `emp_codigo` INT(11) NOT NULL DEFAULT '0',
  `numero_nfce` INT(11) NOT NULL DEFAULT '0',
  `tot_fp_codigo` INT(11) NOT NULL DEFAULT '0',   -- tPag (1, 4, 5, 17, 99)
  `tot_fp_descricao` VARCHAR(60),
  `tot_fp_valor` DOUBLE,
  `tot_fp_vTroco` DOUBLE DEFAULT '0',
  PRIMARY KEY (`emp_codigo`,`numero_nfce`,`tot_fp_codigo`)
) ENGINE=InnoDB DEFAULT CHARSET=latin1;

⚠️ tot_fp_codigo é INT — o código 01 vira 1. A DLL TecnoSpeed faz o zero-padding na hora de gerar o XML.
5.3 Códigos de forma de pagamento (tPag SEFAZ)
Código	Significado
1	Dinheiro
3	Cartão de Crédito
4	Cartão de Débito
17	PIX
99	Outros

Atenção: o nfce_formapgto_vinculada em tab_formapagamento deve estar preenchido com esses valores.

8.3 Validação SQL
sql

-- Totais
SELECT * FROM nfce_totais WHERE emp_codigo=1 AND numero_nfce=X;

-- Formas de pagamento
SELECT * FROM nfce_totais_formapgto WHERE emp_codigo=1 AND numero_nfce=X;

-- Conferência: soma das formas = vNF = vendas.total
SELECT
  (SELECT SUM(tot_fp_valor) FROM nfce_totais_formapgto WHERE emp_codigo=1 AND numero_nfce=X) AS soma_formas,
  (SELECT tot_icms_vNF FROM nfce_totais WHERE emp_codigo=1 AND numero_nfce=X) AS vNF,
  (SELECT total FROM vendas WHERE empresa=1 AND venda=1374) AS total_venda;

Regra de ouro: os três valores devem bater (tolerância R$0,01). Se não baterem, a SEFAZ rejeita (531/532).

9. Pegadinhas Conhecidas

    MesaDetalhesModal.jsx (original) é versão antiga com alert("Em breve"). O correto é MesaDetalhesModal2.jsx.

    pagamentoService.js é o service correto (não mesaService.js).

    SuccessModal é componente genérico — nunca precisa saber de NFC-e. O pai monta o array detalhes[].

    finalizarEEmitir só loga falha da NFC-e. Venda permanece fechada — não desfaz pagamento.

    PowerShell vs cmd: curl é alias de Invoke-WebRequest no PowerShell. Usar curl.exe ou Invoke-WebRequest.

    Quoting em PowerShell: usar aspas simples ('...'). PS não interpreta \ como escape. Comandos em uma linha só (evitar backtick de continuação).

    funcionarios.USER é palavra reservada SQL — usar backticks.

    vendas.vendedor = funcionarios.codigo, não usuarios.codigo.

    tot_fp_codigo é INT — 01 vira 1. A TecnoSpeed faz padding.

    ide_indfinal = 1 (int), não 'sim'.

    Desconto do cabeçalho vs desconto dos itens: precisa distribuir proporcionalmente, senão rejeição 531/532.

    Componente TecnoSpeed não é thread-safe — emissões concorrentes darão pau.

    Integrador TecnoSpeed descontinuado — só COM/ActiveX.
