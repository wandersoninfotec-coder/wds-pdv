5. Problema atual — NCM com alíquotas específicas
Sintoma

Venda com produto cujo NCM = 19059090 pertence à tabela dfe_ncm_nbs_ibs_cbs. O TXT saiu assim:
text

CST_UB13=200        ← carregou certo (da tabela NCM)
cClassTrib_UB14=200003  ← carregou certo
vBC_UB16=134.89     ← calculado com base reduzida
pIBSUF_UB18=0.00    ← ❌ deveria vir da tabela NCM
vIBSUF_UB35=0.00    ← ❌
pIBSMun_UB37=0.00   ← ❌
vIBSMun_UB54=0.00   ← ❌
pCBS_UB56=0.00      ← ❌
vCBS_UB67=0.00      ← ❌
vIBS_UB54a=0.00     ← ❌

Causa raiz

No NfceFiscal::processarReformaTributaria(), quando busca RTC por NCM, zera as alíquotas hardcoded:
php

elseif (!empty($prod['ncm'])) {
    $ncmRtc = $produtoModel->buscarRtcPorNcm($prod['ncm']);
    if ($ncmRtc) {
        $rtc = [
            'CST_IBS_CBS'    => $ncmRtc['cst_ibs_cbs'],
            'cclasstrib'     => $ncmRtc['cclass_trib'],
            'pRedIBS'        => 0, 'pRedCBS' => 0, 'pRedIBSMun' => 0,
            'AliquotaIBSUF'  => 0,     // ← ❌ zera
            'AliquotaIBSMun' => 0,     // ← ❌ zera
            'AliquotaCBS'    => 0,     // ← ❌ zera
        ];
        $origem = 'ncm';
    }
}

6.1 Ver o que a tabela dfe_ncm_nbs_ibs_cbs oferece
sql

SHOW COLUMNS FROM dfe_ncm_nbs_ibs_cbs;
SELECT * FROM dfe_ncm_nbs_ibs_cbs WHERE ncm = '19059090' LIMIT 1;

O que preciso ver:

    Nomes exatos das colunas de alíquota (aliq_ibs_uf, aliq_cbs, p_red_ibs_uf, etc.)

    Valores reais para esse NCM (alíquotas reduzidas, diferimento, crédito presumido)

6.2 Ver o que Produto::buscarRtcPorNcm() retorna

Abre o arquivo models/Produto.php e localiza o método buscarRtcPorNcm(). Precisa retornar todas as colunas de alíquota, não só cst_ibs_cbs e cclass_trib.

Se o SELECT atual for limitado (ex: SELECT cst_ibs_cbs, cclass_trib FROM ...), expandir para incluir as alíquotas.
6.3 Ajustar o NfceFiscal::processarReformaTributaria()

Antes:
php

elseif (!empty($prod['ncm'])) {

6.4 Aplicar as alíquotas 2026 também para NCM?

Se a tabela dfe_ncm_nbs_ibs_cbs já traz os valores certos (0,10% / 0,00% / 0,90% e reduções), não precisa forçar. Mas se ela ainda estiver com valores de 2025 ou 2027, considerar aplicar a mesma regra do item 6.5 do último resumo (forçar mínimo 0,10% em 2026).
